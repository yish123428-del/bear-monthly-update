# 신규 제안 입력 파일 포맷

`scripts/update_status_excel.py`가 `--new-proposals` 옵션으로 받는 .xlsx의 시트 구조.

## 시트 이름

기본 시트 이름: `신규제안` (다른 이름이어도 첫 시트를 자동 사용)

## 컬럼 (3행부터 데이터)

1행: 제목(자유), 2행: 빈줄, 3행: 헤더, 4행~: 데이터

| 컬럼 | 필수 | 예시 | 설명 |
|---|---|---|---|
| 제안 연월 | ✓ | `26년 4월` | 누적요약 시트 첫 컬럼에 들어갈 텍스트 |
| 본부 | | `MKT` | 이메일 본문에서 "MKT" 또는 "영업본부" 등 표시용 |
| 사업부 | | `마케팅1사업부` | 이메일 본문 표시용 (영업부 제안인 경우 사업부명) |
| 팀/사무소 | ✓ | `소화기2사업팀` | 시트 1·2 행 매칭에 사용 |
| 제안자 | ✓ | `김민수` | 누적요약 시트 컬럼 |
| 건수 | ✓ | `1` | 한 명이 여러 건이면 합계 (이메일 표기에 사용) |
| 제안 유형 | ✓ | `의약품 자체개발` | 누적요약 시트 컬럼 |
| 아이디어 유형 | ✓ | `복합제` | 누적요약 시트 컬럼 — 이메일 본문 굵은 글씨 부분에 사용 |
| 제안 내용 | ✓ | `우루사+실리스칸 복합제(UDCA+실리마린)` | 누적요약 시트 컬럼 |
| 검토 결과 | ✓ | `1차 타당성 검토중` | 누적요약 시트 마지막 컬럼 |
| 이메일 표기 | | `복합제 1건 (UDCA + 실리마린 복합제 / 우루사 100mg + 실리스칸 175mg, 자체 개발)` | 비워두면 "{아이디어 유형} {건수}건 ({제안 내용})" 형식으로 자동 생성 |

## 예시

| 제안 연월 | 본부 | 사업부 | 팀/사무소 | 제안자 | 건수 | 제안 유형 | 아이디어 유형 | 제안 내용 | 검토 결과 | 이메일 표기 |
|---|---|---|---|---|---|---|---|---|---|---|
| 26년 5월 | MKT | 마케팅1사업부 | 소화기2사업팀 | 김민수 | 1 | 의약품 자체개발 | 복합제 | 우루사+실리스칸 복합제(UDCA+실리마린) | 1차 타당성 검토중 | |
| 26년 5월 | MKT | 마케팅1사업부 | 호흡피부안과사업팀 | 이영민 | 1 | 의약품 자체개발 | 적응증 개량 | 이지에프 연고/외용액(rhEGF) 신규 적응증(쇼그렌, 외안성 질환 등) | 1차 타당성 검토중 | |

## 주의

- "팀/사무소" 컬럼은 시트 `1. 제안 현황`의 행을 정확히 찾기 위해 매우 중요. 기존 시트에 등록된 팀명과 일치해야 한다.
- 만약 동일 인물이 같은 달에 여러 제안을 했으면 행을 분리해서 각각 입력 (이메일 본문에서 항목별로 표시되도록).
- 사업부/본부는 영업부 사무소 제안의 경우 "사무소" 단위 행 매칭을 위해 비워둘 수 있고, 이때 "팀/사무소" 컬럼에 사무소명(예: `북부2`)을 적는다.
